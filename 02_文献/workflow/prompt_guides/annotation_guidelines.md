# Annotation Guidelines

## 核心规则

```
用户划了高亮/下划线 → 只注释用户划的那几条（数量不限）
用户没划高亮 → AI 智能识别 ~20 个关键概念进行注释
```

## 4 层标注结构

每条 PDF 标注的批注必须包含以下层次：

| 层次 | 内容 | 写法示例 |
|------|------|----------|
| 1️⃣ 定义&背景 | 概念是什么，从哪来 | "Mann-Whitney U 检验是一种非参数检验，不假设正态分布..." |
| 2️⃣ 在本文中的角色 | 作者为什么提它 | "作者用它量化每位被试的内感受准确性，因为..." |
| 3️⃣ 与论证的关联 | 如何服务于核心论点 | "这直接回答了 RQ1——生态条件下能否检测到内感受..." |
| 4️⃣ 批判性延伸（可选） | 你的思考/与其他文献的连接 | "但这里如果改用 meta-d'，结果会不会不同？详见笔记局限一节。" |

格式要求：
- 纯中文（论文原文为英文时）或中文 + 英文术语混写
- 分段清晰，平均 150-300 字/条（用户已有标注）或 100-200 字/条（AI 智能标注）
- **至少 30% 包含批判性思考**（不只是转述）

## 选标策略（AI 智能标注模式）

### 数量控制：~20 条

### 区域分配

| 区域 | 数量 | 选点 | 
|------|------|------|
| Introduction | ~5 | 核心概念定义、理论框架、研究缺口、关键引用 |
| Methods | ~7 | 实验设计关键步骤、统计方法、技术细节、设备/量表 |
| Results | ~4 | 核心统计结果、关键数据、图表发现、出乎意料的结果 |
| Discussion | ~4 | 核心解释、理论意义、局限、未来方向 |

### 优先级原则（从高到低）

1. **论文提出的新概念/新术语**——这些是论文的原创贡献
2. **方法论中让论文有特色的设计决策**——如"为什么用这个统计方法而不是那个"
3. **与你研究方向直接对口的段落**——可引用的、可反驳的、可借鉴的
4. **作者重点强调的结论**——如 p < 0.001、大效应量、新颖发现
5. **作者承认的局限性**——你的研究的切入点

### 不必标的

- 一般性研究背景/领域常识
- 赞助声明/致谢/利益冲突
- 过长的引用罗列
- 已经被摘录的内容

---

## 标注质量自检

```
[ ] 每条标注都有批注（annotationComment）
[ ] 批注不是英文翻译，而是中文的分析/解释
[ ] 非本领域的人读批注能理解核心意思
[ ] 至少有 30% 的批注包含批判性思考（不只是"转述"）
[ ] 标注覆盖了 Intro / Methods / Results / Discussion 四个部分
```

## 好标注 vs 差标注

**差**：对 "Mann-Whitney U test" 的高亮
> 批注：空

**好**：对 "Mann-Whitney U test" 的高亮
> 批注："为什么选 U 检验而不是 t 检验？四大核心原因：(1) 数据非均匀采样——CARED 的自适应通知算法故意不随机，t 检验的均值比较会被扭曲；(2) 心率数据天生右偏；(3) 对极端异常值稳健；(4) 直接对应假设。详情见笔记 Mann-Whitney U 一节。"

**差**：对 "P-factor" 的高亮
> 批注：P因子

**好**：对 "P-factor" 的高亮
> 批注："P 因子 (Caspi et al., 2014) 指精神病理学的共同潜在因子。本文引用它论证内感受障碍与多种精神疾病相关的跨诊断性质——如果内感受真的是 P 因子的一部分，那测量内感受的任务就应该能用于临床筛查。这是本文的底层逻辑：CARED 的临床应用价值建立在这个假设之上。"
