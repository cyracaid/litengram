# Paper Priority Classification

## 重要等级标准

| 等级 | 符号 | 标准 | 投入时间 |
|------|------|------|----------|
| 镇山之宝 | ⛰️ | 直接决定你课题的核心文献，不读懂无法推进 | 4-8h |
| 精兵强将 | ⚔️ | 方法/理论上有重要参考价值 | 2-4h |
| 补充参考 | 📌 | 有趣但非核心，值得了解 | 0.5-1h |
| 过眼云烟 | 🌫️ | 浏览即弃，不值得留痕 | 无笔记 |

## 用途标签

每篇论文还要打一个用途标签：

- **理论奠基**: 提供核心理论框架或概念定义
- **方法借鉴**: 实验范式/统计分析可以移植
- **争议靶子**: 你打算反驳/改进的论文
- **领域综述**: 帮你快速进入一个新方向的入口
- **工具文献**: 提供量表、设备、代码等实用资源

## 重要性类别（研究版图定位）

| 类别 | 含义 |
|------|------|
| 🪨 理论基石 | 没有它，你的研究没法论证存在价值 |
| 🗺️ 路标 | 它指出了你的下一步实验设计 |
| 🧪 工具箱 | 你直接用它报告的方法/软件/代码 |
| ⚠️ 岔路口 | 它的结论提醒你"这条路可能走不通" |
| 🔭 地平线 | 和你的方向有关但需要更多文献佐证 |

## 读前定位清单

```
[ ] 这篇论文的核心发现是什么？（一句话概括）
[ ] 它解决了什么缺口/问题？
[ ] 它和我自己的研究有什么直接或间接关系？
[ ] 我期望从它身上学到什么？
    （一个具体方法 / 一个理论 / 一个引用 / 一个反驳点）
```

> 如果读完三段还不能回答以上问题，先跳到 Discussion 的总结段。这叫高效率。
