# Literature Analysis Framework (LitForge Core)

## 最高目标

**以 PI 的思维深度，读懂每一篇论文。**

不在于"读了多少篇"，而在于——读完之后，你是否具备了：

1. **复刻**论文的能力（方法学理解到达可编程的精度）
2. **批判**论文的能力（限度和替代方案了然于胸）
3. **嫁接**论文的能力（从中提取一个方法/概念，直接服务于你的研究）
4. **反驳**论文的能力（在一个点上比作者想得更深，甚至发现作者忽略的关键矛盾）

LitForge 不读——**锻造**。每篇论文不是拿来看，而是拿来锻造成自己的武器。

---

## 三遍读法

### 第一遍：10 分钟侦察
读 Title → Abstract → 图表 → 结论段。回答三个问题：
1. 这篇论文的核心发现是什么？
2. 它和我的研究有关系吗？
3. 值得花 2 小时精读吗？

确定重要等级：⛰️ / ⚔️ / 📌 / 🌫️

### 第二遍：标注式精读（60-120 分钟）
逐段阅读，按 annotation_guidelines.md 标注 PDF，完成 5 维度解剖。

### 第三遍：笔记+嫁接（30-60 分钟）
1. 写 Zotero 子笔记
2. 写本地 .md 文件到 `CAD/litreview/`
3. 标注"行动计划"——这篇论文让你接下来做什么

## 5 维度分析范式

### 维度 1：解剖刀——已知·缺口·目标

| 要素 | 追问 | 标准 |
|------|------|------|
| **已知 (Known)** | 领域里已经确认了什么？ 最核心的 2-3 个前提？ | 3-5 点 |
| **缺口 (Knowledge Gap)** | 前人没做什么？ 哪条路没走？ 哪个问题悬而未决？ | 2-3 点 |
| **目标 (Research Aim)** | 本文究竟要回答什么具体问题？ 一句话说清楚 | 1 句 |

判别标准：能为不相干专业的人说清楚来龙去脉，才算读懂。

### 维度 2：方法论三层拆解

```
层 1: 操作描述 → 作者写了什么
      被试是谁？任务长什么样？流程怎么走？
      
层 2: 设计逻辑 → 问三个 WHY (LitForge 深度标志)
      为什么选这个人数？（有无 power analysis？）
      为什么用这个实验设计？（不是其他设计？）
      为什么要做这些统计分析？（不是其他方法？）

层 3: 方法局限 → 反向验证
      如果降低样本量，结论还成立吗？
      如果换一种统计方法，结论会变吗？
      这个设计在什么条件下会失效？
```

> **LitForge 深度标志**：层 2 的分析。普通人写"用了 U 检验"；LitForge 写"为什么必须用 U 检验——4 个原因"。

### 维度 3：核心发现

按重要性排序 2-4 个发现，每个发现回答：
- 这个发现是什么？（数字 + 效应量 + 方向）
- 支持 / 挑战 / 修正了什么理论？
- 你信不信这个效果量？为什么？

> 对每个核心发现的统计方法做"合理性检查"——如果审稿人问"这个方法对吗"，你要能说清楚。

### 维度 4：战略嫁接（最关键）

永远带着"这篇论文能给我什么"去读。必须输出至少一个具体的嫁接方案：

| 类型 | 追问 |
|------|------|
| 🔧 方法/工具 | 这个范式/分析技术能直接移植吗？ |
| 📐 理论框架 | 它的理论模型能解释我的数据吗？ |
| 💡 概念 | 它提出的新概念能借用或转用吗？ |
| 📝 引述段落 | 哪一段话可以直接放进 proposal？ |
| 🔥 反驳点 | 我能不能用我的数据反驳它的结论？ |

### 维度 5：重要性判断

这篇论文在**你个人研究版图里**属于：

| 类别 | 含义 |
|------|------|
| 🪨 理论基石 | 没有它，你的研究没法论证存在价值 |
| 🗺️ 路标 | 它指出了你的下一步实验设计 |
| 🧪 工具箱 | 直接用它报告的方法/软件/代码 |
| ⚠️ 岔路口 | 它的结论提醒你"这条路可能走不通" |
| 🔭 地平线 | 和你的方向有关但需要更多文献佐证 |

## 质量检查清单

每篇论文完成后逐项检查：

```
[ ] 标注覆盖了 Introduction / Methods / Results / Discussion
[ ] 每条标注都有完整批注（见 annotation_guidelines.md）
[ ] 笔记包含全部 8 个必须部分（见 literature_note_template.md）
[ ] 至少有一个战略嫁接的具体方案（维度 4）
[ ] 至少有一个你自己的追问/质疑/反驳
[ ] 笔记末尾有"行动计划"
[ ] Zotero 同步完成
[ ] 本地 .md 已保存到 CAD/litreview/
```

## 常见错误

| 错误 | 表现 | 纠正 |
|------|------|------|
| 记流水账 | 笔记全是"作者做了什么" | 加 30% 的"为什么这样做"+"我怎么用" |
| 无结构标注 | 标注散落无逻辑 | 按 4 层结构逐条写批注 |
| 拒绝批评 | 只总结不质疑 | 写一段"如果你是审稿人，你会提什么意见" |
| 忘记链接 | 读完了不知道和自己的关系 | 读之前想："我期望从这篇拿到什么" |
| 过度收藏 | 标的太多 = 什么都没标 | AI 模式下 ~20 条高质量 > 50 条水货 |
