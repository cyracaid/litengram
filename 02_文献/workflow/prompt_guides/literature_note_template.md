# Literature Note Template

## 8 个必须部分

每份阅读笔记必须包含以下 8 个部分（缺少任何一块的分析都不完整）：

```
📋 基本信息
📚 研究背景（已知·缺口·目标）
🧠 理论背景（核心理论/关键概念/理论→本研究逻辑链）
🔬 研究方法（被试/设计/流程/分析 + WHY 分析）
💡 核心发现（主要发现/理论意义/局限 + 批判分析）
🔗 与你领域的关系（战略嫁接——具体方案）
⭐ 重要性判断
📄 原文摘要
```

---

## 完整模板

```markdown
# 📖 [主题领域] 文献精读 — [日期]

## 关键词: [3-5 个核心关键词]

## [论文完整标题]

### 📋 基本信息

- **重要等级**: {⛰️镇山之宝 / ⚔️精兵强将 / 📌补充参考}
- **第一作者**: [姓名] | [机构] | [实验室]
- **通讯作者**: [姓名]
- **发表**: [年份] | [期刊]
- **DOI**: [doi]
- **Zotero**: `itemKey` | **PDF**: `attachmentKey` | **笔记**: `noteKey`
- **引用**: ~[次数]

### 📚 研究背景

**已知 (Known)**

- 领域内已有的关键发现
- 与本论文最直接相关的 2-3 个背景

**知识缺口 (Knowledge Gap)**

- 尚不清楚/未解决的问题
- 前人方法的局限

**研究目标 (Research Aim)**

- 本文要解决的具体问题（一句话）

### 🧠 理论背景

**核心理论框架 (Theoretical Framework)**

- 核心理论名称 + 来源文献
- 2-3 句话解释该理论的核心主张

**关键概念 (Key Constructs)**

- 定义本文涉及的核心概念
- 每个概念按对应重要等级的粒度解释

**理论→本研究的逻辑链 (Rationale)**

- 用箭头/流程图展示理论如何推导出研究假设

### 🔬 研究方法

**被试 (Participants):** N, 性别, 年龄, 排除标准

**实验设计 (Experimental Design):** 范式+变量+结构

**实验流程 (Procedure):** 分阶段

**数据分析 (Data Analysis):** 统计方法+关键参数+软件

> **WHY 分析（层 2）**：解释关键设计决策背后的理由。
> 为什么选这个被试数？为什么用这个设计？为什么用这个统计方法？

### 💡 核心发现

**主要发现 (Main Findings):** 按重要性排序 2-4 个结果

**理论意义 (Theoretical Implications):** 支持/挑战/修正了什么理论

**局限性 (Limitations):** 作者自评 + 你的批判性评估

> 对每个核心发现的统计方法做合理性检查。

### 🔗 与你领域的关系

- 这篇论文如何对齐你的研究方向
- 你可以借用的具体方法/概念（战略嫁接）
- 可引用的引述段落（英文）

### ⭐ 为什么这篇重要

简要说明本文在你的研究版图中的战略价值。

### 📄 原文摘要

> 英文摘要原文
```

## 概念解释粒度

| 重要等级 | 粒度 |
|---------|------|
| ⛰️镇山之宝 | 每个关键术语详细解释：定义→拆解→在本研究中的角色→延伸/关联 |
| ⚔️精兵强将 | 核心 2-3 个术语深入解释 |
| 📌补充参考 | 仅解释最晦涩的 1 个术语 |

> 好的标准：一个研究生看到你的解释，不需要再查第二篇论文就能理解这个概念。

## 写笔记原则

```
原则 1: 和自己的研究对齐。每一段话至少回答一次"So what?"
原则 2: 写英文引述段落。发现可以放进 proposal 的段落，直接摘录并标注引用位置
原则 3: 写自己的"吐槽"和追问。不同意的地方标记为【反驳】【疑问】【延伸】
原则 4: 笔记末尾必须有"行动计划"——这篇论文让我接下来做什么？
```

## 不好笔记 vs 好笔记

| 维度 | 不好 | 好 |
|------|------|----|
| 方法 | "用了 U 检验" | "为什么必须用 U 检验而不是 t 检验？4 个原因" |
| 结果 | "发现了反向元认知" | "4/30 的人 AUC<0.5，这可能对应 4 种不同机制" |
| 嫁接 | "这篇文章很好" | "我的 Phase 2 可以用同样的 ROC 方法，加上情绪调节变量" |
