# Paper Priority Classification (LitEngram)

> 用途：论文分级、类型分类、用途标签和阅读策略选择。
> 阅读阶段：Stage 0 · Intake 时必读。

## 论文类型七分类

每篇论文先判定类型，这影响方法论拆解策略：

| 类型 | 英文 | 含义 |
|------|------|------|
| 🧪 实证 | Empirical | 有实验/数据收集的原创研究 |
| 📐 方法 | Methods | 提出新方法/工具/范式 |
| 🧠 理论 | Theory | 提出理论框架或概念模型 |
| 📚 综述 | Review | 系统/叙述性综述 |
| 📏 基准 | Benchmark | 数据集/指标/竞赛基线 |
| 🔄 复现 | Replication | 重复/验证已有发现 |
| 🗣️ 观点 | Position | 立场文/评论/观点 |

> 类型决定维度 2 的策略：Empirical / Methods / Benchmark 走方法论三层拆解；Review / Theory / Position 走论证结构拆解（主张链条→证据类型→推理跳跃点）。

## 重要等级标准

| 等级 | 符号 | 标准 | 投入时间 |
|------|------|------|----------|
| 镇山之宝 | ⛰️ | 直接决定你课题的核心文献，不读懂无法推进 | 4-8h |
| 精兵强将 | ⚔️ | 方法/理论上有重要参考价值 | 2-4h |
| 补充参考 | 📌 | 有趣但非核心，值得了解 | 0.5-1h |
| 过眼云烟 | 🌫️ | 浏览即弃，不值得留痕 | 无笔记 |

## 阅读策略四档

等级决定策略：

| 等级 | 策略 | 标注密度 | 笔记长度 | 分析深度 | 审稿人自审 |
|------|------|---------|---------|---------|-----------|
| ⛰️ | **Deep** | ~20 条 | 完整 8 部分 | 5 维度全深度 | ✅ 强制 |
| ⚔️ | **Standard** | ~12-15 条 | 完整 8 部分，简洁 | 5 维度，层 2 简化 | 🔲 可选 |
| 📌 | **Fast** | ~5-8 条 | 基本信息 + 核心发现 + 嫁接 | 维度 1 + 3 + 4 为主 | ❌ 跳过 |
| 🌫️ | **Skip** | 0 | 无笔记 | 不分析 | ❌ 跳过 |

## 用途标签

每篇论文还要打一个用途标签：

- **理论奠基**: 提供核心理论框架或概念定义
- **方法借鉴**: 实验范式/统计分析可以移植
- **争议靶子**: 你打算反驳/改进的论文
- **领域综述**: 帮你快速进入一个新方向的入口
- **工具文献**: 提供量表、设备、代码等实用资源

## 重要性类别（研究版图定位）

| 类别 | 含义 |
|------|------|
| 🪨 理论基石 | 没有它，你的研究没法论证存在价值 |
| 🗺️ 路标 | 它指出了你的下一步实验设计 |
| 🧪 工具箱 | 你直接用它报告的方法/软件/代码 |
| ⚠️ 岔路口 | 它的结论提醒你"这条路可能走不通" |
| 🔭 地平线 | 和你的方向有关但需要更多文献佐证 |

## 读前定位清单

```
[ ] 这篇论文的类型是？（Theory / Methods / Empirical / Review / Benchmark / Replication / Position）
[ ] 这篇论文的核心发现是什么？（一句话概括）
[ ] 它解决了什么缺口/问题？
[ ] 它和我自己的研究有什么直接或间接关系？
[ ] 我期望从它身上学到什么？
    （一个具体方法 / 一个理论 / 一个引用 / 一个反驳点）
[ ] 阅读策略：Deep / Standard / Fast / Skip
```

> 如果读完三段还不能回答以上问题，先跳到 Discussion 的总结段。这叫高效率。
