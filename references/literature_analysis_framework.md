# Literature Analysis Framework (LitEngram Core)

> 用途：LitEngram 的核心分析引擎。定义三遍读法、5 维度分析范式、质量标准和常见错误。
> 阅读阶段：Stage 3 · Deep Analysis 时必读。

## 最高目标

**以 PI 的思维深度，读懂每一篇论文。**

不在于"读了多少篇"，而在于——读完之后，你是否具备了：

1. **复刻**论文的能力（方法学理解到达可编程的精度）
2. **批判**论文的能力（限度和替代方案了然于胸）
3. **嫁接**论文的能力（从中提取一个方法/概念，直接服务于你的研究）
4. **反驳**论文的能力（在一个点上比作者想得更深，甚至发现作者忽略的关键矛盾）

LitEngram 不读——**编码**。每篇论文不是拿来看，而是拿来编码成一段持久的研究记忆（engram）。

---

## 三遍读法

### 第一遍：10 分钟侦察 → SCQA 速记

读 Title → Abstract → 图表 → 结论段。输出 SCQA 四行：

```
S（Situation / 情境）: 领域背景共识是什么？
C（Complication / 困境）: 当前有什么缺口或矛盾？
Q（Question / 问题）: 本文要回答什么？
A（Answer / 答案）: 核心发现是什么？
```

同时回答三个问题：
1. 这篇论文的核心发现是什么？
2. 它和我的研究有关系吗？
3. 值得花 2 小时精读吗？

确定重要等级：⛰️ / ⚔️ / 📌 / 🌫️

> **注意**：SCQA 只是第一遍的速记骨架。第二遍精读时，把 S+C 扩写成维度 1 的"已知"+"缺口"，Q 对应"目标"，A 对应维度 3 的"主要发现"——不要两处重复写。

### 第二遍：标注式精读（60-120 分钟）

逐段阅读，按 annotation_guidelines.md 标注 PDF，完成 5 维度解剖。

### 第三遍：笔记+嫁接（30-60 分钟）

1. 执行审稿人自审（⛰️ 级强制，⚔️ 级可选）
2. 写 Zotero 子笔记
3. 写本地 .md 文件到 `CAD/litreview/`
4. 标注"行动计划"——这篇论文让你接下来做什么

## 5 维度分析范式

### 维度 1：解剖刀——已知·缺口·目标

| 要素 | 追问 | 标准 |
|------|------|------|
| **已知 (Known)** | 领域里已经确认了什么？最核心的 2-3 个前提？ | 3-5 点 |
| **缺口 (Knowledge Gap)** | 前人没做什么？哪条路没走？哪个问题悬而未决？ | 2-3 点 |
| **目标 (Research Aim)** | 本文究竟要回答什么具体问题？一句话说清楚 | 1 句 |

**缺口可分类（适用则分类，不强制填满三格）：**

- **Known Knowns（已知已知）**: 领域共识但本文没涉及——标记为"不在本文范围内"即可
- **Known Unknowns（已知未知）**: 公认的未解问题——这是论文试图填补的
- **Unknown Unknowns（未知未知）**: 本文揭示的新问题方向——**优先喂给维度 4 战略嫁接**，往往是你自己课题的切入点

> 判别标准：能为不相干专业的人说清楚来龙去脉，才算读懂。

### 维度 2：方法论三层拆解

**checklist 域判定（先跑这个，决定维度 2 用哪个清单）**

按三个信号判定 `domain`，结果写入下游（Stage 6 按它选方法节模板，Stage 5 按它选审稿清单）：

| 信号 | psych 信号 | nlp 信号 |
|------|------|------|
| 术语 | 被试 / N / 量表 / 方差分析 / 效应量 / 问卷 | 模型 / 数据集 / 评测指标 / baseline / GPU / 消融 / prompt |
| venue | 心理学期刊（JEP / 心理科学 / Psychological...）| ACL / EMNLP / NAACL / COLING / arXiv-CS |
| 内容 | 行为/问卷/脑数据 + 统计推断 | 训练/评测/榜单 + 代码 |

```
domain = psych        → 统计完整性 checklist（下）
domain = nlp          → NLP 评测公平性 checklist（下）
domain = hybrid       → 两个 checklist 都跑（认知NLP/心理语言学/LLM心理学评估/行为+AI 混合）
domain = review-theory → 不跑 checklist，走论证结构拆解
```

> hybrid 判定俗例：LLM 心理学评估论文 = 被试(N) + 模型 + 指标 → 两者都上。两域互补：NLP 论文吃 psych 的显著性/效应量纪律；psych 用 AI 工具的论文吃 nlp 的可复现性/污染检查。

**规则**：若论文类型为 Review / Theory / Position（无被试与实验设计），**跳过方法论三层拆解**，改为拆论证结构（主张链条→证据类型→推理跳跃点）。其余维度照常。

```
层 1: 操作描述 → 作者写了什么
      psych: 被试是谁？任务长什么样？流程怎么走？
      nlp: 基线/模型/数据/评测 分别是什么？

层 2: 设计逻辑 → 问三个 WHY（LitEngram 深度标志）
      psych: 为什么选这个人数？（有无 power analysis？）
             为什么用这个实验设计？（不是其他设计？）
             为什么要做这些统计分析？（不是其他方法？）
      nlp: 为什么用这个模型/基座？为什么选这些指标？为什么这个数据规模/split？

      统计完整性 checklist（psych 域；nlp/hybrid 域可跳过大部分，改跑下方 NLP 清单）：
      [ ] 效应量报告（effect size，如 Cohen's d, η², r）
      [ ] 置信区间（95% CI）
      [ ] 多重比较校正（Bonferroni / FDR / 等其他）
      [ ] 先验功效分析（a priori power analysis）
      [ ] 预注册（pre-registration）
      ─ 注：2015 年前论文缺预注册属常态，不扣分
      [ ] 原始数据可用性（open data）
      [ ] 分析方法预先指定 vs. 事后分析（exploratory vs. confirmatory）

      NLP 评测公平性 checklist（nlp 域；hybrid 域与上表并行跑）：
      [ ] 基线公平：基线是否同预算 tune 过？不是碾压未调参数基线？
      [ ] 显著性检验：报 significance（bootstrap / 配对检验）还是只报 mean？
      [ ] 指标选择：为什么选这个 metric？换指标结论变吗？（cherry-pick 检查）
      [ ] 多次运行：报单次还是多次 seed 均值±方差？
      [ ] 消融完整：每个新组件都有对应消融？还是一次全消？
      [ ] 数据污染/泄漏：训练/测试重叠？预训练数据 contamination？
      [ ] 人类评估：评估者数 + 指导语 + 一致性（kappa/ICC）？
      [ ] 代码/权重公开：可复现性承诺？

层 3: 方法局限 → 反向验证
      psych: 如果降低样本量，结论还成立吗？
             如果换一种统计方法，结论会变吗？
             这个设计在什么条件下会失效？
      nlp: 换基座模型，结论变吗？换 seed / 换评测指标 / 换 prompt 模板，结论变吗？
           （任何一个"换"翻车 → 该结论标记【对设置敏感】）
```

> **LitEngram 深度标志**：层 2 的分析。普通人写"用了 U 检验"；LitEngram 写"为什么必须用 U 检验——4 个原因"。

### 维度 3：核心发现

按重要性排序 2-4 个发现，每个发现回答：
- 这个发现是什么？（数字 + 效应量 + 方向）
- 支持 / 挑战 / 修正了什么理论？
- 你信不信这个效果量？为什么？

**Claim-Evidence 映射（仅对 2-4 个核心发现做，不对全文每个 claim）：**

| 指标 | 选项 |
|------|------|
| 证据强度 | Direct（本文数据直接支持）/ Indirect（引他文或推论）/ Unsupported（有主张无直接证据） |
| 证据来源 | Empirical / Simulation / Theoretical / Review |

> **用途**：抓 Discussion 里从 Direct 悄悄滑向 Unsupported 的推理滑坡——这是"反驳"能力的核心抓手。

### 维度 4：战略嫁接（最关键）

永远带着"这篇论文能给我什么"去读。必须输出至少一个具体的嫁接方案，且**必须落到 research_profile.md 里的具体项目/Phase**：

| 类型 | 追问 |
|------|------|
| 🔧 方法/工具 | 这个范式/分析技术能直接移植吗？ |
| 📐 理论框架 | 它的理论模型能解释我的数据吗？ |
| 💡 概念 | 它提出的新概念能借用或转用吗？ |
| 📝 引述段落 | 哪一段话可以直接放进 proposal？ |
| 🔥 反驳点 | 我能不能用我的数据反驳它的结论？ |
| 🧰 实现/算力 | （nlp/hybrid）能落地吗？搬它的模型/方法，我的 GPU/预算跑得动吗？数据 license 允许吗？（算力门槛显式评估——nLP 搬模型有显存/成本，psych 搬范式无成本，必须分别判断） |

### 维度 5：重要性判断

这篇论文在**你个人研究版图里**属于：

| 类别 | 含义 |
|------|------|
| 🪨 理论基石 | 没有它，你的研究没法论证存在价值 |
| 🗺️ 路标 | 它指出了你的下一步实验设计 |
| 🧪 工具箱 | 直接用它报告的方法/软件/代码 |
| ⚠️ 岔路口 | 它的结论提醒你"这条路可能走不通" |
| 🔭 地平线 | 和你的方向有关但需要更多文献佐证 |

## 质量检查清单

每篇论文完成后逐项检查：

```
[ ] 结构门禁：研究背景(已知/缺口/目标)、理论背景(框架/概念/逻辑链)、关键引用、研究方法(被试/设计/流程/分析)、核心发现、与你领域关系、重要性、原文摘要——逐项存在且非空
[ ] 标注覆盖了 Introduction / Methods / Results / Discussion
[ ] 每条标注都有完整批注（见 annotation_guidelines.md）
[ ] 笔记包含全部 8 个必须部分（见 literature_note_template.md）
[ ] 至少有一个战略嫁接的具体方案（维度 4）
[ ] 嫁接已落到 research_profile.md 里的具体项目
[ ] 至少有一个你自己的追问/质疑/反驳
[ ] 笔记末尾有"行动计划"
[ ] Zotero 同步完成
[ ] 本地 .md 已保存到 CAD/litreview/
[ ] （⛰️ 级）审稿人自审已完成（见 reviewer_protocol.md）
```

## 常见错误

| 错误 | 表现 | 纠正 |
|------|------|------|
| 记流水账 | 笔记全是"作者做了什么" | 加 30% 的"为什么这样做"+"我怎么用" |
| 无结构标注 | 标注散落无逻辑 | 按 4 层结构逐条写批注 |
| 拒绝批评 | 只总结不质疑 | 执行审稿人自审（reviewer_protocol.md） |
| 忘记链接 | 读完了不知道和自己的关系 | 读之前想："我期望从这篇拿到什么" |
| 过度收藏 | 标的太多 = 什么都没标 | AI 模式下 ~20 条高质量 > 50 条水货 |
