# Stage 6: Engram Note Synthesis (v2.0)

> 由 LitEngram meta-skill 调度。将上文所有产出合成为**展开式人类批判性阅读笔记**。

## 输入

从主 agent 处接收：
- Stage 1-2 产出（优先级 + 上下文）
- Stage 3 产出（分析文本 + 概念白话素材）
- Stage 4-5 产出（内联标注清单 + 审稿人报告）

## 步骤

### 1. 读参考文件

- `references/literature_note_template.md` — 8 锚点骨架 + 内容门禁 + 文风规则
- `references/concept_excavation.md` — 概念白话解释的内容要求

### 2. 合成精读

按 8 锚点写（`基本信息 / 这篇在讲什么 / 核心论证 / 作者论证与证据 / 局限与批判 / 我的疑问 / 待验证 / 和我的研究的关系`，`原文摘要` 作附录）：

- **写法随论文类型变**：实验/方法类第 4 节写"主张+证据"；理论/综述类同标题下写"立场→论证链→证据类型→跳跃点"。
- **不强制每篇都有全部 8 节**：确实没有的内容并进段落，不硬造小标题；但"核心论证 / 局限与批判 / 我的疑问 / 和我的研究的关系"通常必含。
- **白话、连贯、先解释后评价、去标签、emoji 极简**——详见模板的写作哲学。术语第一次出现先白话再英文。
- **概念就地讲**：重大概念可用 `#### 概念名` 小标题，之后是白话段落，不用字段标签。
- **AI 标注 / 关键引用不进精读**：它们已在原文内联；精读里需要时用一句话带过。

摘要从 Zotero 的 `abstractNote` 读取，不改写。

**neuroscience 版特别注意**：
- fMRI 专属细节（刺激范式、采集参数、预处理、分析）并进"核心论证 / 作者论证与证据"叙述，不单列字段
- `## 作者论证与证据` 里每条发现都点明证据强度（直接 fMRI 激活 / 间接行为关联 / 理论）与来源
- `## 和我的研究的关系` 覆盖 fMRI 复现的算力/显存门槛
- 遇 fMRI 术语（搜光峰、GLM 设计矩阵、ROI、MVPA 等）就地白话解释

### 3. 内容门禁检查

写入前跑模板的**内容门禁**（不是旧的结构门禁）。任一条为否 → 重写该段，不靠补小标题过关。通过后返回。

## 输出

返回完整精读 Markdown 字符串给主 agent。

**格式要求**：
- 纯 Markdown（无原始 HTML）
- 遵守 `literature_note_template.md` 的输出兼容层规则
- 概念/辨析表只在真的更清楚时用；不滥用表格
