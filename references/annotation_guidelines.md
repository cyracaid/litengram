# Annotation Guidelines (LitEngram v1.1)

> 用途：定义 PDF 标注的 4 层结构、混合标注模式、质量标准和格式规范。
> 阅读阶段：Stage 4 · Cognitive Annotation 时必读。

## 核心规则

```
有 highlight/underline → 模式 A（混合）：
  步骤 1: 对已有 annotation → SQLite UPDATE comment（安全，不动 position）
  步骤 2: AI 补充 ~10 条 → 写入笔记 📌 关键标注 节 + 可选 PDF 高亮
  
无 highlight/underline → 模式 B（纯 AI）：
  生成 ~20 条 → 全部写入笔记 📌 关键标注 节 + 可选 PDF 高亮

> 架构约束（v1.6 更新）：itemAnnotations.position 需要合法的 PDF 坐标（pageIndex + rects）。
> v1.2 曾断言「SQLite 不可能构造合法 position」——**这个断言已被证伪**（2026-09 实战验证）：
> PyMuPDF (`get_text("words")` / `get_text("dict")`) 能精确定位任意引文的字符级坐标，
> 经 y 轴翻转校准后即可合法写入 annotation，Zotero 会正常渲染高亮。
> 前提是**坐标系校准**：Zotero position 的 y 轴原点在页面底部（PDF 原生坐标系），
> PyMuPDF 的 y 轴原点在顶部，二者满足 `zotero_y = pageHeight − pymupdf_y`。
> 校准方法见 zotero_workflow.md §四。
>
> 因此两条路都合法：
> - 保守路径（默认）：AI 标注全部嵌入笔记 📌 节，不碰 PDF（零风险）
> - 高亮路径（可选，见 zotero_workflow.md §四）：用 PyMuPDF 生成合法 position，批量 INSERT
> UPDATE 已有 annotation 的 comment 字段始终安全（不改 position）。
```

## 4 层标注结构

每条 PDF 标注的批注必须包含以下层次：

| 层次 | 内容 | 写法示例 |
|------|------|----------|
| 1️⃣ 定义&背景（含溯源） | 概念是什么，从哪来——**若含关键术语，按 concept_excavation.md 的 9 层规格展开** | "Mann-Whitney U 检验是一种非参数检验，不假设正态分布...源于 Wilcoxon (1945) 的秩和检验..." |
| 2️⃣ 在本文中的角色 | 作者为什么提它 | "作者用它量化每位被试的内感受准确性，因为..." |
| 3️⃣ 与论证的关联 | 如何服务于核心论点 | "这直接回答了 RQ1——生态条件下能否检测到内感受..." |
| 4️⃣ 批判性延伸（可选） | 你的思考/与其他文献的连接 | "但这里如果改用 meta-d'，结果会不会不同？详见笔记局限一节。" |

格式要求：
- 纯中文（论文原文为英文时）或中文 + 英文术语混写
- 分段清晰
- **含概念深挖的标注不限字数**——宁深勿浅，该多长就多长
- **至少 30% 包含批判性思考**（不只是转述）
- AI 补充的标注以 `🤖 [AI补充] ` 前缀开头

> **涉及关键结论时**，可在批注末尾用标记标明证据地位，防止日后误把争议结论当共识引用：
> - 📘 Formal（领域共识，教科书级证据）
> - 🔬 Frontier（仍有争议，前沿探索）

## 混合标注模式（模式 A：用户已划线）

两步执行：

### 步骤 1：注释全部用户高亮

对每一条用户 highlight/underline 按 4 层 + 概念溯源深挖，写入对应 annotation 的 comment。

- 若标注原文含关键术语，第 1 层必须按 `concept_excavation.md` 的 9 层规格展开（深度随论文等级）
- 存在易混概念时做并排辨析表

### 步骤 2：AI 补充 ~10 条

扫描全文，找出用户没划但高价值的段落——满足以下任一条件：
(a) 含用户很可能不懂的术语
(b) 是让论文成立的承重方法决策
(c) 是核心论点的关键证据句
(d) 作者强调的反直觉结论或局限

为这 ~10 条新建 annotation（写入 SQLite `items` + `itemAnnotations`），做同等深度的挖掘。
**以 `🤖 [AI补充] ` 前缀开头**，让用户一眼区分人划的和 AI 补的。

### 锚定约束（技术关键）

高亮的渲染锚点 = `position`（pageIndex + rects），**不是** `text`。构造方式见 zotero_workflow.md §四（PyMuPDF 字符级定位 + y 翻转）。

- `text` 字段是侧栏显示的元数据，存引文原文即可（无需与 PDF 逐字符一致）
- 定位失败（PDF 扫描版/无文本层）→ **退而在笔记的"概念详解"区展开**，不硬造 annotation
- 若 PDF 为扫描件（`get_text("dict")` 无文本）→ 无法生成合法 position，放弃该条高亮

## AI 智能标注模式（模式 B：无划线）

### 数量控制：~20 条

### 区域分配

| 区域 | 数量 | 选点 | 
|------|------|------|
| Introduction | ~5 | 核心概念定义、理论框架、研究缺口、关键引用 |
| Methods | ~7 | 实验设计关键步骤、统计方法、技术细节、设备/量表 |
| Results | ~4 | 核心统计结果、关键数据、图表发现、出乎意料的结果 |
| Discussion | ~4 | 核心解释、理论意义、局限、未来方向 |

### 优先级原则（从高到低）

1. **论文提出的新概念/新术语**——这些是论文的原创贡献
2. **方法论中让论文有特色的设计决策**——如"为什么用这个统计方法而不是那个"
3. **与你研究方向直接对口的段落**——可引用的、可反驳的、可借鉴的
4. **作者重点强调的结论**——如 p < 0.001、大效应量、新颖发现
5. **作者承认的局限性**——你的研究的切入点

### 不必标的

- 一般性研究背景/领域常识
- 赞助声明/致谢/利益冲突
- 过长的引用罗列
- 已经被摘录的内容

## 标注质量自检

```
[ ] 每条标注都有批注（annotationComment）
[ ] 批注不是英文翻译，而是中文的分析/解释
[ ] 每个术语标注都溯源到了提出者/原始文献（或标注来源不确定）
[ ] 存在易混概念时做了辨析
[ ] 非本领域的人读批注能理解核心意思
[ ] 至少有 30% 的批注包含批判性思考（不只是"转述"）
[ ] AI 补充的标注以 🤖 前缀正确标记
[ ] 标注覆盖了 Intro / Methods / Results / Discussion 四个部分
```

## 好标注 vs 差标注

**差**：对 "Mann-Whitney U test" 的高亮
> 批注：空

**好**：对 "Mann-Whitney U test" 的高亮
> 批注："为什么选 U 检验而不是 t 检验？四大核心原因：(1) 数据非均匀采样——CARED 的自适应通知算法故意不随机，t 检验的均值比较会被扭曲；(2) 心率数据天生右偏；(3) 对极端异常值稳健；(4) 直接对应假设。溯源：Wilcoxon (1945) 提出的秩和检验，Mann & Whitney (1947) 独立推广为两样本版本。详情见笔记 Mann-Whitney U 一节。"

**差**：对 "P-factor" 的高亮
> 批注：P因子

**好**：对 "P-factor" 的高亮
> 批注："P 因子 (Caspi et al., 2014, *Clinical Psychological Science*) 指精神病理学的共同潜在因子——不同精神疾病共有的方差由一个潜在因子解释。本文用它论证内感受障碍与多种精神疾病相关的跨诊断性质。📘（领域共识）"

## 📌 关键标注 节格式（嵌入笔记正文）

当无法创建 PDF annotation 时，AI 标注以 Markdown 嵌入笔记正文：

```markdown
### 📌 关键标注 (AI Annotation Highlights)

| # | 原文 | 区域 | 批注 |
|---|------|------|------|
| 1 | "...exact PDF text..." | Intro | 1️⃣定义 2️⃣本文角色 3️⃣论证关联 4️⃣批判延伸 |
| 2 | "...exact PDF text..." | Methods | ... |
| ... | ... | ... | ... |

覆盖区域: Intro (N条) / Methods (N条) / Results (N条) / Discussion (N条)
```

每行批注按 4 层结构写——但长度控制在一段内（~80-150 字），不同于独立 PDF annotation 的不限字数版。

## Stage 4 输出小结

Stage 4 执行完成后，在输出末尾打印小结：

```
用户高亮: N 条 → 已全部注释
AI 补充:  M 条 → 覆盖区域: [Intro / Methods / Results / Discussion]
总计: N+M 条标注已写入 Zotero
```
