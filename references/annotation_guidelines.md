# Annotation Guidelines (LitEngram v2.0)

> 用途：定义 PDF 内联标注的写法、混合标注模式、质量标准。
> 阅读阶段：Stage 4 · Cognitive Annotation 时必读。
> **v2.0**：标注**内联写在原文里**（Zotero 侧栏），输出写成白话段落；不再用 `1️⃣定义 2️⃣角色 3️⃣论证 4️⃣延伸` 标签，也不再把标注汇总进精读。
> 分工：AI 标注/引用 = 原文层；精读 = 批判性阅读笔记（见 `literature_note_template.md`）。

---

## 核心规则

```
有 highlight/underline → 模式 A（混合）：
  步骤 1: 对已有 annotation → SQLite UPDATE comment（安全，不动 position）
  步骤 2: AI 补充 ~10 条 → 写入 PDF 内联标注（Zotero 侧栏批注）

无 highlight/underline → 模式 B（纯 AI）：
  生成 ~20 条 → 全部写入 PDF 内联标注

> 架构约束：itemAnnotations.position 需要合法 PDF 坐标（pageIndex + rects）。
> 用 PyMuPDF (`get_text("words")` / `get_text("dict")`) 能精确定位引文，经 y 轴翻转校准
> （zotero_y = pageHeight − pymupdf_y）即可写入合法 annotation，Zotero 正常渲染。
> 校准与批量 INSERT 见 zotero_workflow.md §四。
> 保守路径（默认）：标注只写内联 comment，不新建 PDF 高亮（零风险）；
> 高亮路径（可选）：用 PyMuPDF 生成合法 position 批量 INSERT。
> UPDATE 已有 annotation 的 comment 始终安全（不改 position）。
```

**关键一点**：内联标注是**给读原文的你**看的，贴在有上下文的原文旁边，所以可以比精读短。精读页**不重复**列这些标注。

---

## 批注怎么写（白话，不露标签）

每条批注写成人话，**不要** `1️⃣定义 / 2️⃣本文角色 / 3️⃣论证关联 / 4️⃣批判延伸` 这种字段串。内部推理时你可以按四层过一遍，但输出要合成一段自然的话。

内部自查维度（写之前脑子里过一遍，不写出来）：

| 维度 | 内容 |
|------|------|
| 定义&背景 | 概念是什么、从哪来——若含关键术语，按 `concept_excavation.md` 的白话要求讲清 |
| 在本文中的角色 | 作者为什么提它 |
| 与论证的关联 | 如何服务于核心论点 |
| 批判性延伸（可选） | 你的思考 / 与其他文献的连接 |

**输出风格示例：**

> 🤖 作者这里说的 epiphenomenal decoding，直白讲是：可解码不等于被读出，也不等于因果相关。本文用它说明现有相关证据不足，所以后面必须做 causal test。对 MVPA 研究也是个提醒：解码精度 ≠ 行为因果。

格式要求：
- 纯中文，英文术语可就地保留
- 一段话，连贯；含概念解释时该长就长，不限字数
- 至少 30% 的批注包含你自己的判断/质疑（不只是转述）
- AI 补充的批注以 `🤖 ` 前缀开头（区分人划 vs AI 补）

> 涉及关键结论时，可在批注里用一句话点明证据地位（"这是领域共识" / "这仍有争议"），但不必加 📘/🔬 图标。

## 混合标注模式（模式 A：用户已划线）

### 步骤 1：注释全部用户高亮

对每条用户 highlight/underline，按上面的白话风格写 comment。
若标注原文含关键术语，用白话讲清它（深度随论文等级）。

### 步骤 2：AI 补充 ~10 条

扫描全文，找用户没划但高价值的段落——满足以下任一：
(a) 含用户很可能不懂的术语
(b) 让论文成立的承重方法决策
(c) 核心论点的关键证据句
(d) 作者强调的反直觉结论或局限

为这 ~10 条新建内联 annotation，同样白话风格，以 `🤖 ` 前缀开头。

### 锚定约束（技术）

高亮渲染锚点 = `position`（pageIndex + rects），不是 `text`。构造见 zotero_workflow.md §四。
- `text` 字段存引文原文即可
- 定位失败（扫描版/无文本层）→ 退而在概念解释里讲，不硬造 annotation
- 扫描件（无文本）→ 放弃该条高亮

## AI 智能标注模式（模式 B：无划线）· ~20 条

### 区域分配

| 区域 | 数量 |
|------|------|
| Introduction | ~5 |
| Methods | ~7 |
| Results | ~4 |
| Discussion | ~4 |

### 优先级（从高到低）

1. 论文提出的新概念/新术语
2. 让论文有特色的方法设计决策（"为什么用这个而不是那个"）
3. 与你研究方向直接对口的段落
4. 作者重点强调的结论
5. 作者承认的局限性

### 不必标的

- 一般性背景/领域常识
- 赞助声明/致谢/利益冲突
- 过长的引用罗列
- 已摘录的内容

## 标注质量自检

```
[ ] 每条标注都有批注（annotationComment）
[ ] 批注不是英文直译，而是中文的解释/判断
[ ] 每个术语解释讲清了它从哪来（或标注来源不确定）
[ ] 有易混概念时讲了区别
[ ] 非本领域的人读批注能懂核心意思
[ ] 至少 30% 的批注含批判性思考（不只是转述）
[ ] 批注是白话段落，没有 1️⃣/【定义】这类字段标签
[ ] AI 补充的标注以 🤖 前缀正确标记
[ ] 覆盖了 Intro / Methods / Results / Discussion
```

## 好批注 vs 差批注

**差**：对 "Mann-Whitney U test" 的高亮
> 批注：空

**好**：对 "Mann-Whitney U test" 的高亮
> 🤖 为什么这里用 U 检验而不是 t 检验？作者的理由大致四点：数据不是随机采的——CARED 的自适应通知故意不随机，t 检验比均值会被扭曲；心率天生右偏；U 检验对极端值稳健；而且它直接对应"两样本是否同分布"的假设。溯源是 Wilcoxon (1945) 的秩和检验，Mann & Whitney (1947) 推广到两样本。

**差**：对 "P-factor" 的高亮
> 批注：P因子

**好**：对 "P-factor" 的高亮
> 🤖 P 因子（Caspi et al., 2014）指精神病理学的共同潜在因子——不同精神疾病共有的方差由一个潜在因子解释。本文用它论证内感受障碍与多种精神疾病相关是跨诊断的。这是领域共识。

## Stage 4 输出小结

执行完成后在输出末尾打印：

```
用户高亮: N 条 → 已全部注释（内联）
AI 补充:  M 条 → 覆盖区域: [Intro / Methods / Results / Discussion]
总计: N+M 条内联标注已写入 Zotero
（注意：标注不进精读页；精读只写批判性阅读笔记）
```
