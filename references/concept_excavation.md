# Concept Excavation Engine (LitEngram v2.0)

> 用途：定义"讲清一个概念"的内容要求与文风——从"转述定义"升级为"白话解释 + 溯源 + 拆解 + 辨析 + 连回研究"。
> 阅读阶段：Stage 3（收集素材）+ Stage 6（写进精读）时必读。
> **v2.0**：保留旧版的内容要素，但**废除字段标签**（不再写 `**溯源**：`、`**核心机制**：`），
> 要求把这些要素**自然融进白话段落**。文风对齐 `literature_note_template.md` 的写作哲学。

---

## 核心问题

写概念不是"给这个词下一个定义"。要让一个研究生读完**不需要再查第二篇文献就能懂**——它从哪来、由谁提出、和邻近概念怎么区分、在本文里干什么、能怎么接到自己的课题上。

但 v1.x 把这些内容写成了字段表（`**定义**：…`、`**溯源**：…`），读起来像数据库条目。v2.0 要求：**内容是这些，形式是段落，不露字段标签。**

---

## 讲清一个概念时要覆盖的内容要素

写概念时，下列要素都要有（按需取舍，不必逐条齐平，但缺关键项 = 没讲清）。**注意：这些是"要讲到的内容"，不是"要写的字段名"。**

| 要素 | 要求 |
|------|------|
| 白话定义 | 第一句就用最直白的人话讲清（不用学术腔）。先讲"它其实是说……"，再给英文术语 |
| 溯源 | 这个概念最早由谁、哪篇文献、哪一年提出？属于哪个理论传统？本文是自己提出还是引用别人？（追到原始出处；追不到就明说"来源不确定"并标明所属框架） |
| 拆解 | 把概念拆开：脑区→解剖位置与分区；心理构念→维度；统计方法→假设与步骤 |
| 易混辨析 | 有容易混的邻近概念时，说清区别。并排对比真的更清楚时才用表格，别为形式硬造 |
| 核心机制/功能 | 它怎么运作、起什么作用 |
| 在本文中的角色 | 作者为什么在这里提它，服务于哪个论点/问题 |
| 与用户研究的关联 | 落到 research_profile.md 的具体项目/Phase。写不出具体关联就明说"与当前 profile 无直接接口"，别硬编 |
| 人话类比 | 一个生活化比喻（不是复述定义） |

> 罗列要素是为了不漏，不是让人按这个顺序写字段。输出时按论文行文逻辑，把这些融成一段或几段话。

## 输出格式（v2.0）

- 概念**就地讲**——在它出现的论证里展开，不单列成"概念字段区"。
- 重大概念可用一个 `#### 概念名（English Term）` 小标题方便跳转；非重大概念不必加标题。
- 正文是连贯段落，不用 `- **定义**：` 这种字段列表。
- emoji 极简（全文只留 `⛰️⚔️📌` 等级符号）。

---

## 递归挖掘规则

解释概念 X 时若碰到一个**承重的**子术语 Y（去掉了 X 就讲不清），就地给 Y 一个简短白话解释（一两句 + 类比即可）。

- 承重判断：去掉 Y，X 是否讲不清？
- 最大递归深度：2 层
- 非承重的子术语不挖

## 深度分级

| 重要等级 | 处理哪些概念 | 深度 |
|----------|-------------|------|
| ⛰️镇山之宝 | 全文关键术语 | 内容要素齐全，溯源 + 辨析 + 类比到位 |
| ⚔️精兵强将 | 核心 3-5 个术语 | 同上 |
| 📌补充参考 | 最晦涩的 1-2 个 | 白话定义 + 溯源 + 类比即可 |

## 质量红线（自检）

```
[ ] 第一句就是白话，不是学术定义转述
[ ] 溯源到位（谁提出、哪年；或明确标"来源不确定"）
[ ] 有易混概念就讲了区别
[ ] 有一个真实的人话类比，不是复述定义
[ ] 连回了用户的具体研究（或明确说无接口）
[ ] 没有字段标签（没写"**溯源**："这种）
[ ] 一个研究生读完不用再查第二篇文献就能懂
```

## 范例（对齐文风）

**反例（v1.x 字段体，禁止）：**

> **一句话粗暴定义**：给罕见事件更高采样概率。
> **溯源**：Csikszentmihalyi & Larson (1987) 的 ESM。
> **核心机制**：通知概率与心率经验频率成反比。
> **在本文中的角色**：让 CARED 捕获全心率范围。

**正例（v2.0 白话段落）：**

#### 自适应采样（Adaptive Sampling）

自适应采样是给罕见的事件更高的采样概率，确保数据覆盖全范围，而不是均匀地抽。它属于"自适应经验采样"家族的思路，心理学里最早由 Csikszentmihalyi & Larson (1987) 的 Experience Sampling Method 奠基；本文把它直接用到生理信号的频率匹配上。做法是让通知概率与心率的经验频率成反比——越少见的心率值，越被优先采到。

在本文里，这套采样是 CARED 能在四周内抓到每位被试**整个心率范围**、而不是只在静息态测一次的关键，也是全文最核心的方法创新。

对你的研究也有直接接口：你的 Garmin 手环 + EMA 设计同样面对"日常心率范围广、采样预算有限"的矛盾；若想在内感受的生态测量里复现或扩展 CARED，这个算法可以直接搬。

打个比方：标准静息态测量好比"只在停车场试一辆车"，自适应采样则是"高速公路、山路、市区拥堵路段都跑一遍"。

（旧版"内感受准确度"范例此处从略，改写原则相同：白话定义先讲清"做得准 vs 信得足 vs 知道自己准不准"三者的区别，再给 Garfinkel 溯源与三维度辨析，最后接到你 Phase 2 的 MCI 操作化。辨析表仅在三个维度并排对比时使用。）

## 引用溯源（专用场景）

给论文参考文献做溯源时，不必在精读里列清单——引用和逐条批注属于**原文层**（Zotero 内联标注）。
若精读里需要提到某条关键引用，用一句话带过即可（"关键引用见原文内联标注"），不堆角色符号清单。
