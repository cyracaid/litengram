# Roadmap — LitEngram

---

## Version 1.3 (Current - 2026-09-09)

Status: ✅ STABLE

Features:
- 4-layer annotation system
- Ollama LLM integration
- Notion sync
- Knowledge fingerprinting
- Full documentation

## Version 1.4 (Q4 2026)

Status: 📅 PLANNED

Features:
- Web UI for knowledge graph visualization
- Obsidian/Logseq/Roam integration
- Batch paper import
- Custom LLM prompts
- API server (FastAPI)

## Version 2.0 (2027 H1)

Status: 🔮 PROPOSED

Features:
- Multi-LLM support (Claude, GPT-4, Llama)
- Real-time collaborative annotations
- Academic paper recommendations
- Citation network visualization
- Mobile companion app

## Long-term Vision (2027+)

- Cross-language support
- Advanced reasoning (chain-of-thought, self-critique)
- Publication-ready formatted citations
- Full-text search across all papers
- Team/lab collaboration features
