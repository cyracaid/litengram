## 主线当前状态（一分钟版）

**问题**：恐音症的严重度，是由身体感觉被**登记**得多强驱动的，还是由这些感觉被**解读**得多威胁驱动的？

**数据**：CAD Lab 恐音症研究（N=80，临床 50/对照 30），全部使用现有变量。

**三条硬约束**：零新增采集 / 不依赖 fMRI 预处理 / 分析可分段。

**新颖性定位（已诚实下调）**：不是新框架——核心主张已于 2025 年发表。定位为**对已有模型的首次竞争性量化检验**，增量在于登记与解读同时投入同一模型（先前研究在 OCD 样本且无内感受测量），以及试次层特异性检验。

### ⭐ 最新框架候选（2026-08-21 第二轮查证后，我认为是目前最强的）

> **已有研究用无监督方法（高斯混合模型）在恐音症中发现了「预期型 / 反应型」两个亚组，但未给出机制解释。本研究检验登记—解读分解能否解释这一结构。**

为什么更强：**不需要宣称任何新颖性**（"为已观察到的现象提供机制"是被完全接受的贡献类型）；**不需要论证这个区分重要**（无监督方法已证明它在数据里真实存在）；**假设可证伪**（S/A 分解预测不了亚组归属则框架错）；**功效更好**（组间比较而非交互检验）。

⚠ 前提：**必须先读原文**确认亚组定义与聚类变量。详见 `01_misophonia/frameworks/FRAMEWORK候选_为已有亚组提供机制.md`

## 贯穿全程的三条工作规则

来自 2026-08-21 一天内三次撞车的教训（详见 `01_misophonia/proposals/CHANGELOG_方案演化.md`）：

1. **先查证，后写入。** 任何框架级主张或实证主张，先检索再写。内感受 × 情绪 × 精神病理是极度拥挤的领域。
2. **先查数据实际是什么，再设计分析。** v1→v2 的推翻是因为假设了任务类型没查协议。
3. **新颖性是有粒度的。** 框架级最稀有；新人群 / 新方法 / 竞争性检验 / 构念分解都算新颖，且更难被抢。

**并且**：网络检索足以发现"已经有人做了"，**不足以支撑"没有人做过"**。正式提案前须用 PubMed / PsycINFO 布尔式系统检索。
