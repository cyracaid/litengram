## 这条线在问什么

从一个语感观察出发：作为中文母语者，在描述某类人际/权力/情绪状态时，会不自觉切换到英语（patronizing, validate, dynamic）——但这不是能力问题，也不是"中文缺词"这么简单。

一路推下来，问题逐步精确化，最终落在：

> **一个文化如何决定，哪些人类经验值得被压缩成一个日常可用的概念单位（everyday conceptual unit）？**

以及它的类型学版本：

> **中文与英语在词汇化/语法化层面被"强制标记"的维度本身是错位的** —— 英语侧的强制类目常落在"精确定位机制"，中文侧常落在"说话者的情感姿态"与"关系角色位置"。

这个提法比"中文缺少 patronizing"硬得多，也比 individualism/collectivism 二分法的颗粒度细得多。

## 三条可能的研究出口（按成熟度排）

**出口一：类型学语料研究（最可执行）**
抓取中英近五年社交媒体高频造词，标注词根类别（kinship-role / trait-disposition / behavior / other），检验两语言分布差异。预测：中文命名人际权力失衡的新词系统性偏向亲属-角色词根（爹味、妈味、家长式、断亲），英文偏向特质/行为词根（patronizing, gaslighting, mansplaining）。

**出口二：双语情绪颗粒度实验（与实验室数据可对接）**
中英双语者在两种语言模式下的情绪细分任务 + 内感受测量。Barrett 的 emotion granularity 与内感受准确性有既有关联，而 CAD Lab 的 MAIA-2、内感受任务、EMA 正好都在。**这是这条线唯一能直接接上实验室现有数据的出口。**

**出口三：divergence 作为因变量（最有野心，也最不成熟）**
把 verbal self-report 与生理信号当作两套独立生成的理论，测量两者后验分布之间的散度，并检验 code-switch 是否发生在 divergence 峰值。与既有的 discourse marker leakage 论文是姊妹研究关系。

## 与威胁门控 proposal 的接口

两条线看似无关，实际上共享同一个理论内核：

| | 威胁门控 proposal | 本线 |
|---|---|---|
| 核心问题 | 威胁评价如何调节身体信号→心理的传导权重 | 语言如何决定哪些经验被赋形为可命名单位 |
| 共同机制 | **precision weighting**：什么被赋予诊断权重 | **conceptual compression**：什么被赋予命名资格 |
| 共同工具 | predictive processing / 层级贝叶斯 | 同 |
| 共同数据 | MAIA-2、内感受任务、EMA | 同（出口二） |

**可能的合流点**：emotion granularity 既是语言现象（概念颗粒度），也是内感受现象（Barrett 已论证二者关联）。如果中文口语 register 在某一整块关系性/权力性情绪概念上系统性粗粒度，那么"用中文思考时的情绪分化"与"内感受准确性"的关系，是一个同时属于两条线的可测问题。

这意味着不必二选一 —— 出口二可以作为威胁门控 proposal 的一个语言学扩展 study。

## 一句提醒（给未来的自己）

这条线最大的风险不是想得不够深，而是**想得太漂亮而失去可检验性**。03 号文件里的四条批判都需要被正面处理，尤其是习得语境混淆 —— 如果不控制它，整个因果箭头方向可能是反的。

另一个风险：一旦有了"距离"或"摩擦度"这个数字，很容易被悄悄征用成"该往哪个方向矫正"的处方，把原本想避开的西方个体主义中心论，用客观计算的外壳重新走私回来。这一点在 02 号文件末尾有更详细的讨论。
