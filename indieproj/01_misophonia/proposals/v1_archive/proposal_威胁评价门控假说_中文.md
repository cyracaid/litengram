# 威胁评价对"身体—心理"耦合的门控作用
## 从人口层面证据到机制层面验证

> 作者：동채하 (CAI DONG)
> 版本：v1.0 draft — 2026-08-21
> 用途：与 허주연 교수님 会议讨论用 / 个人研究方向 proposal
> 关联实验室项目：Misophonia 神经机制研究 / 신진과제 纵向研究

---

## 摘要

我在中国综合社会调查（CSS 2023，全国样本）中发现并经七重验证：**对社会资源再分配的"掠夺性/威胁性解读"会门控（收紧）身体健康与心理健康之间的耦合强度**。该效应通过 Bonferroni 校正、在六项稳健性检验下存活、具备判别效度、且独立于负性情感倾向。但跨文化复制（韩国 KGSS、欧洲 ESS9、WVS7）显示该通路是**文化情境特异**的。

这一结果的方法学价值大于其构念的普适性：它把"威胁评价门控身体—心理耦合"这一形式化假说提了出来，但人口层面的横断数据无法回答它究竟发生在**生理信号层**还是**信号解读层**。本 proposal 提出用 CAD Lab 现有的两套数据在机制层面重新检验这一假说：

- **Study 1（恐音症研究，问卷层）**：威胁负荷是否门控内感受觉知与症状严重度的耦合；恐音症临床组作为"感觉—威胁解读"病理的天然模型。
- **Study 2（신진과제，EMA within-person）**：把"耦合"从统计交互项转化为真实的日内动态，并首次分离**客观生理信号**与**主观身体感知**两条通路，从而定位门控的发生层级。

## 〇之前：核心问题

### 一句话

> **身体信号转化为心理痛苦的强度，由施加在信号之上的先验决定——而这个先验，作用在信号本身，还是作用在对信号的解读？**

### 展开

身体状态向心理状态的传导强度不是固定的。决定它的不只是信号本身的强弱，还有一层先验：**什么样的身体状态值得被当作需要警觉的信号，什么样的可以被当作背景噪音。**

这个先验有两个来源，它们是同一件事的两个时相：

- **早期关系经验塑形它** —— 一个身体或情绪状态是否曾被命名、被回应。若从未被命名，关于"什么算正常"的先验就从未被更新。
- **当下的威胁评价调用它** —— 处境被读作威胁时，身体信号被赋予更高的诊断权重。

把两者统一起来的是 precision weighting：**先验决定什么被赋予诊断权重。** 这也是为什么本 proposal 用层级贝叶斯而不是普通调节模型作为形式框架。

### 由此产生的可分层问题（本 proposal 的核心贡献）

先验的调节作用发生在哪一层？

| | 主张 | 可观测后果 |
|---|------|-----------|
| **H-信号层** | 威胁先验改变生理反应本身 | 客观生理指标随先验变化 |
| **H-解读层** | 生理信号不变，改变的是信号→情绪的传导权重 | 客观生理不变，主观感知→情绪的斜率变化 |

**这个区分在任何纯自评数据里都做不出来**，因为自评同时包含了信号和对信号的解读，两者已经混在一个数字里。它需要同一时刻同时具备客观生理与主观感知的数据。

### 三个项目如何汇聚到这里

| 项目 | 观察到什么 | 层级证据 | 局限 |
|------|-----------|---------|------|
| **梦日记 N=1**（已投稿） | 两年病理性出血在 384 条梦记录与 1.8MB 醒时日记中零次出现；而一次急性妇科事件在确诊前 32 天进入表征 | 信号一直在，表征层拒绝了它 → **解读层门控的直接证据** | N=1，无法推广，无客观生理 |
| **CSS Phase 1**（人群） | 威胁性解读收紧身体→心理耦合（b = +0.035, 七重验证）；SES 为二阶调节 | 显示效应有规模、有文化边界 | 自评单条目，**无法定位层级** |
| **CAD Lab 数据** | 待分析 | 客观生理（Garmin / HRV / 内感受任务表现）与主观感知（MAIA / BPQ / EMA 自报）并存 | —— |

**三者不是三个散项目：N=1 提出了机制，人群数据显示它有规模但不能定位层级，实验室数据是唯一能定位层级的地方。**

### 为什么这个问题现在可以问

CAD Lab 的两套数据同时具备分离两层所需的最低配置——客观生理与主观感知在同一批被试、同一时间窗内并存。这不是常见配置，也是本 proposal 必须建立在实验室数据而非公开数据上的唯一理由。

## 〇、设计约束（贯穿全文，优先于任何理论考量）

本 proposal 的全部研究设计受三条硬约束。**任何与之冲突的想法一律排除或降为长期方向，无论其理论价值多高。**

### 三条约束

1. **零新增采集** —— 只使用实验室已在采集的变量。不要求在现有协议上追加任何测量、任何量表、任何任务条目。
2. **不依赖 fMRI 预处理** —— 影像预处理管线是最慢的瓶颈。主要分析必须建立在问卷、行为任务、EMA 与可穿戴数据之上；fMRI 仅作为可选扩展，不进入主线。
3. **数据累积可分段** —— 分析必须能在样本未收满时以中期 n 跑出可解释结果，而不是必须等全样本完成。

### 为什么写死这三条

- **时间窗**：一年毕业，不具备等待完整数据集的余裕
- **行政成本**：纯二次分析通常只需研究者追加，不需 IRB 变更；一旦要求新增测量即触发变更报告，周期不可控
- **累积速度**：问卷与 EMA 数据在扫描进行期间持续累积，不受影像进度约束——这是唯一能在一年内产出 preliminary result 的数据流

### 由此产生的取舍

本 proposal 主动放弃了若干理论上更有意思、但需要新增测量的方向（语言变量、双语情绪颗粒度、冻结生理范式、常态校准 vignette 等，记录于 `../个人项目_语言与心智化/06_开放问题与下一步.md`）。**换取的是可执行性，这个交换是有意识做出的，不是能力所限。**

### 约束下的具体分析清单

| # | 分析 | 用到的现成变量 | 依赖 fMRI？ | 可分段？ |
|---|---|---|---|---|
| A | **内感受三维分离**（主推）<br>K-CTQ 情感忽视 → accuracy / sensibility / awareness 的特定分离 | 内感受任务、MAIA-2、BPQ-SF-A、K-CTQ、IDAS-II、SPSQ | ❌ 否 | ✅ n≈35–40 |
| B | **EMA 睡眠主客观差异**<br>差异本身作为域特异的校准指标 | Garmin 客观睡眠、EMA 睡眠日记、IDAS-II Insomnia、K-CTQ | ❌ 否 | ✅ n≈25–30 |
| C | **accuracy–sensibility gap 预测恐音症严重度** | 同 A，加 AMISOS-R | ❌ 否 | ✅ n≈35–40 |

分析 A 与 C 落在 Study 1（恐音症样本），分析 B 落在 Study 2（신진과제 EMA）。三者共用同一形式假说 `M ~ S × A`。

### ⚠ 三个决定可行性的未知（会议必问，按重要性排）

1. **内感受任务是否记录信心评分？** —— 没有信心评分就算不出 awareness 维度，分析 A 塌一半，C 不受影响。
2. **EMA 问卷里有没有睡眠条目？Garmin 睡眠数据的导出粒度与格式？** —— 决定分析 B 能否成立。
3. **内感受与恐音症严重度这条线是否已有人在做？** —— 决定分析 C 是否该主动提。

**这三个问题的答案直接决定哪个分析能开始，优先于本 proposal 第八节中的任何其他问题。**

## 一、背景：CSS Phase 1 的结果与其真实定位

### 1.1 已完成的工作

使用 CSS 2023 全国样本，检验模型 `心理健康 ~ 身体健康 × 威胁性解读`：

| 项目 | 结果 |
|------|------|
| 核心交互 (f4c_3 × PH) | b = +0.035, p = .0002，通过 Bonferroni |
| 稳健性 | 六项 stress test 全部存活（最弱：HC3 稳健标准误 p = .012） |
| 效应方向 | 威胁性解读**收紧**身体→心理耦合（r 由 .590 升至 .673） |
| 通路特异性 | 只门控"身体→心理"，**不**门控"认知评价→心理" |
| 判别效度 | injustice（−0.021，反向）、fairness、f4c_2、主观社会经济地位 **均不门控** |
| 混淆排除 | 控制负性情感及其与 PH 的交互后，系数不降反增（.035 → .047, p < .0001） |
| 压力负荷补充 | stress_total 连续交互通过 Bonferroni（HC3 p = .005），但分组 Fisher z 不支持（p = .476），定为 A− 级补充证据 |

### 1.2 跨文化复制：部分失败，但有信息量

- **韩国 KGSS 2023**：三阶交互（PH × MISTRUST × RANK）显著（p = .025），HC3 下边缘（p = .063）。原报告结论为"方向相反"，但**该结论已查明有误**（见 1.2.1）。构念错位（BEFAIR 测人际不信任 ≠ f4c_3 的系统性掠夺解读）仍是有效的次要解释。

#### 1.2.1 已修正：KGSS 的"方向不一致"结论是基于废弃版本的误判

核查 `phase0_KGSS_replication_results.md` 后确认：

- 该报告 **B1 节**引用的 CSS 数字是正确的 v2 版本（f4c_3，β = +0.033, p = .0002，收紧）
- 但 **B3 节的 CSS 简单斜率表**（0.65 / 0.51 / 0.64 / 0.55，呈现"减弱"）来自 **v1 废弃分析**（f4c_mean，α = −0.408，已判定无效）。报告 F2 节的代码引用亦指向 `phase1-1-opencode/`，即 v1 目录。
- 因此该报告 B1 与 B3 内部自相矛盾，而"两样本方向不一致"的结论建立在错误的 CSS 基准之上。

**以 v2 为基准重新解读**：

| | 低 SES/RANK 组 | 高 SES/RANK 组 |
|---|---|---|
| CSS v2（f4c_3） | 收紧（整体 r .590 → .673） | 收紧 |
| KGSS（MISTRUST） | **收紧**（2.21 → 3.34） | 松开（1.93 → 1.57） |

即：KGSS 并非干净的方向相反，而是**条件性一致**——在低社会经济地位组中方向与 CSS 一致（收紧），仅在高地位组中反转。显著的三阶交互（β = −0.441, p = .025）正是捕捉了这一分化。

需保留的保守性：B1 零控制扫描中 KGSS 的 BEFAIR 交互确实方向相反（β = −0.653, p = .028），且反转后的 MISTRUST 虽方向一致但不显著（β = +0.344, p = .303）。因此**不能 claim "KGSS 复制成功"**，恰当的表述是"部分条件下一致，且 SES 可能是二阶调节变量"。

**理论意涵**：若 SES 决定威胁评价是收紧还是松开身心耦合，则门控本身是有条件的。这为本 proposal 增加了一个可检验的推论 —— 详见 H1.5 与 H2.5。
- **欧洲 ESS9 / WVS7**：反再分配态度在两个数据集中均**松开**耦合（ESS b = −.072；WVS7 b = −.006），方向与 CSS 相反；政治不信任在 ESS 中收紧（b = +.038，与 CSS 一致）但在 WVS7 中松开（b = −.034）；"靠运气"信念无效应。

**结论**：f4c_3 通路是中国情境特异的。这应当被框定为**贡献而非缺陷**——它界定了效应的文化边界条件。

### 1.3 为什么要转向实验室数据

CSS 的三个结构性局限，恰好是 CAD Lab 数据能解决的：

1. **横断 + between-person**：只能推断"人群中身体差的人如果同时持威胁性解读，心理更差"，无法说明个体内部的动态过程。
2. **身体状态只有自报**：无法区分门控发生在**真实生理信号**层面，还是在**对身体信号的解读**层面。这是理论上最关键的分歧点，CSS 完全无法回答。
3. **威胁评价是宏观社会构念**：距离临床心理的机制层次太远，难以对接神经/生理证据。

因此下一步不是继续在跨国横断数据里堆样本，而是**下沉到有客观生理测量、有 within-person 重复测量、有临床样本的数据里**重新检验同一个形式化假说。

## 二、理论框架：威胁评价门控假说

### 2.1 假说的形式化表述

> 身体状态向心理状态的传导强度，不是固定的，而是被个体对处境的威胁性评价所调节。当处境被解读为威胁性的，身体信号被赋予更高的诊断权重，因而更强地传导为心理痛苦。

三个部件：

- **S（身体状态）**：客观生理信号，或对身体信号的主观感知
- **A（威胁评价）**：对处境/身体信号的威胁性解读，作为门控变量
- **M（心理结果）**：情绪、症状

形式：`M ~ S × A`，预测 `A` 的交互系数为正（收紧）。

### 2.2 与既有理论的接口

| 框架 | 接口 |
|------|------|
| Garfinkel 三维内感受模型 (2015) | Accuracy / Sensibility / Awareness 可分离 → S 的测量学基础 |
| 预测加工 / 内感受推断 | 威胁性先验提高身体预测误差的精度权重 → 门控的计算解释 |
| Threat Imminence Continuum (Fanselow, Mobbs) | 威胁评价按迫近度分段 → A 的分层结构 |
| 躯体化 / 焦虑敏感性 | "对身体感觉的灾难化解读"是本假说的临床近亲 |

### 2.3 关键理论分歧点（本研究的核心贡献）

门控发生在哪一层？

- **H-信号层**：威胁评价改变的是生理反应本身（真实心率上升更多）
- **H-解读层**：威胁评价不改变生理信号，只改变信号→情绪的传导权重

**CSS 无法区分这两者，因为只有自报身体状态。** Study 2 用 Garmin 客观生理与 EMA 自报身体感知的双通路建模，可以直接检验：若门控只出现在"自报身体→情绪"路径而不出现在"客观生理→情绪"路径，则支持 H-解读层。

这是本 proposal 相对 CSS 最实质的理论推进。

## 三、Study 1：恐音症研究 — 威胁负荷对内感受—症状耦合的门控

### 3.1 为什么恐音症是理想模型

恐音症（misophonia）的核心病理是：**对中性或轻微的躯体性声音（咀嚼、呼吸）做出威胁性解读，并伴随被放大的身体反应**（心动过速、过度换气、肌肉紧张）。这在结构上正是本假说的临床实例——感觉输入 → 威胁解读 → 放大的身心反应。

先行神经影像研究亦支持：前岛叶（既是显著性探测核心，也是内感受加工核心）在恐音症中过度激活（Kumar et al., 2017），提示内感受异常参与其中。实验室的 IRB 协议中也明确将内感受列为研究目的之一。

### 3.2 数据来源

CAD Lab「Misophonia 신경 기전 연구」：
- N = 80（临床组 50 / 对照组 30），18–39 岁
- 从先行行为学研究（N = 159，其中 145 人同意后续联系；临床 101 / 对照 44）中筛取 → **无需冷启动招募**
- 单次 2 小时 session；在线问卷 14 份

可用变量：

| 角色 | 量表 |
|------|------|
| S 身体感知 | MAIA-2（37题，8子量表）、BPQ-SF-A（26题，身体感觉觉察） |
| A 威胁负荷 | LTE-Q（近6个月威胁性生活事件）、K-CTQ（童年创伤，5子量表） |
| M 心理结果 | IDAS-II（99题，维度化抑郁焦虑，含 Panic / Social Anxiety / Insomnia / Dysphoria 等子量表） |
| 判别变量 | SPSQ（一般感觉加工敏感性）、AMISOS-R（恐音症严重度） |
| 组别 | 临床组 / 对照组（双盲实施） |

### 3.3 假设

- **H1.1**：威胁负荷（LTE-Q）正向调节内感受觉知（MAIA-2 Noticing / BPQ）与症状严重度（IDAS-II）的关联。即高威胁负荷者，身体觉察与症状的耦合更强。
- **H1.2（判别效度）**：一般感觉加工敏感性（SPSQ）**不**产生同样的门控效应。若 SPSQ 也门控，则效应并非威胁特异，而是泛化的感觉敏感性所致。这一判别设计直接沿用 CSS 中已验证有效的策略。
- **H1.3（组间）**：门控强度在恐音症临床组中大于对照组。
- **H1.4（内部分解，探索性）**：MAIA-2 的 8 个子量表中，"觉察类"（Noticing, Body Listening）与"调节态度类"（Not-Worrying, Not-Distracting, Trusting）承担不同角色——前者属 S，后者本身已带威胁评价色彩，可能与 A 部分重叠。此分解可检验门控是否内生于内感受结构本身。
- **H1.5（资源条件，源自 KGSS 修正）**：门控强度受个体资源条件调节。在低资源条件下（低主观社会经济地位、高童年创伤负荷）威胁评价收紧耦合，而在高资源条件下该效应减弱甚至反转。此假设直接来自 1.2.1 节对 KGSS 的重新解读，是本 proposal 中唯一由跨文化数据反推出的可检验推论。

### 3.4 分析计划（预注册要点）

- 主模型：`IDAS-II ~ MAIA-2 × LTE-Q + 年龄 + 性别 + 组别`
- 稳健标准误（HC3）作为默认，与 CSS 保持一致
- 多重比较：对主要假设族做 Bonferroni 校正
- 连续调节 + 分组 Fisher z **双路验证**（CSS 中 stress_total 正是在此处露出弱点，须预先声明）
- 混淆控制：负性情感倾向（IDAS-II Dysphoria）及其与 S 的交互，复用 CSS 的排除逻辑
- 敏感性分析：临床组/对照组分别建模；替换 S 的操作化（MAIA vs BPQ）

### 3.5 可行性

**最高。** 纯问卷分析，不依赖 fMRI 预处理管线；被试池现成；问卷数据在扫描进行中即持续累积。n ≈ 35–40 即可跑出可解释的初步结果。

## 四、Study 2：신진과제 EMA — 门控发生在信号层还是解读层

### 4.1 数据来源

CAD Lab「신진과제」4年纵向研究（现处 baseline 采集期）：

| 模块 | 内容 |
|------|------|
| EMA | 2周，每日 2–7 次（平均 6 次），Cadtracker app |
| 客观生理 | Garmin vivoactive 5：心率、睡眠、活动、佩戴时长 |
| 实验室生理 | HRV（BIOPAC，静息）、炎症标志物 + 皮质醇（可选） |
| 行为 | 执行功能 5 任务（Stroop / antisaccade / plus-minus / keep-track / local-global）、内感受任务 |
| 临床 | SCID 半结构化访谈（每年 ×4）、在线问卷（每6个月 ×8） |
| 影像 | MRI session |

### 4.2 假设

- **H2.1（within-person 耦合存在个体差异）**：日内"身体状态 → 情绪"的传导斜率在个体间存在显著变异（随机斜率方差 > 0）。
- **H2.2（跨层门控）**：该个体差异被威胁评价倾向 / 威胁负荷（LTE-Q、K-CTQ、EMA 瞬时压力评价的个人均值）系统性解释。
- **H2.3（层级定位 — 核心假设）**：门控效应在"**主观身体感知** → 情绪"路径上显著，而在"**客观生理**（Garmin HR/睡眠）→ 情绪"路径上不显著或显著更弱 → 支持 H-解读层。
- **H2.4（睡眠通路）**：前夜睡眠（Garmin 客观 + EMA 睡眠日记自报）对次日情绪的影响同样受威胁评价门控，且客观/自报的分离模式与 H2.3 一致。
- **H2.5（资源条件，对应 H1.5）**：跨层门控效应（H2.2）本身被个体资源条件（主观社会经济地位、童年创伤）二阶调节，方向与 H1.5 一致。若在两套独立数据中均观察到该模式，则 KGSS 的"条件性一致"获得机制层面的支持。

### 4.3 分析计划（预注册要点）

多层模型（三层：beep 嵌套于日，日嵌套于人）：

```
Level 1: 瞬时情绪_ijk ~ β0_jk + β1_jk·(身体状态_ijk - 人均值) + ε
Level 2: β1_jk ~ γ10 + γ11·(威胁评价_k) + u1_jk
```

关键方法学声明（须预先固定）：
- **Centering 策略**：Level-1 预测变量采用 person-mean centering，以严格分离 within/between 方差
- **随机斜率**：必须允许 β1 随机，否则无法检验 H2.1
- **客观与自报双模型**：分别建模而非同时投入，避免共线性掩盖分离模式；再以正式的系数差异检验比较
- **缺失与依从性**：EMA 应答率、Garmin 佩戴时长（协议要求日均未佩戴 < 3 小时）须作为敏感性分析的分层变量
- **多重比较**：对 H2.1–H2.4 构成的假设族做校正

### 4.4 与我已有技能的衔接

我过去半年多独立开发并反复 audit 的 **EMA sleep diary 数据清洗工具**（R package + skill，已近完工，GitHub: cyracaid/sleepdiary-cleaner）正好是 H2.4 的第一环。若能与实验室现有 EMA pipeline 对接，既可服务实验室，也直接构成本研究的数据准备基础。

### 4.5 可行性

**中等偏高，取决于招募速度。** 每名被试的 EMA 数据在 2 周内即完成累积，因此不必等待整个纵向研究结束。n ≈ 25–30 人即可支撑多层模型的初步分析。风险点是 baseline 招募进度与 Cadtracker 数据导出的可及性 —— 这是会议上需要向教授确认的关键信息。
