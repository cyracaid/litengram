# CAD Lab 学习目标与学习计划

> 基于 CAD 文件夹及 CAD 技术文件夹资料整理
> 研究领域：认知情感神经科学 (Cognitive Affective Neuroscience)
> 核心技术栈：fMRI 数据分析 | 机器学习 | 多模态信号处理

---

## 一、学习目标

### 短期目标（1-3个月）
- [ ] **fMRI 基础**：理解 BOLD 信号原理、MRI 物理基础、实验设计（Block / Event-Related）
- [ ] **SPM 实操**：掌握 MATLAB + SPM 进行单被试/组分析的全流程
- [ ] **BIDS 规范**：熟悉 Brain Imaging Data Structure，能完成 DICOM → NIFTI → BIDS 转换
- [ ] **MRI QC**：掌握 T1 + fMRI 图像质量检查流程，识别常见伪影
- [ ] **线性代数基础**：掌握向量、矩阵、PCA/SVD 等神经影像核心数学

### 中期目标（3-6个月）
- [ ] **统计学习**：掌握 ISLR 核心内容（回归、分类、重抽样、正则化、树模型、SVM）
- [ ] **GLM 进阶**：深入理解一阶/二阶分析，多重比较校正
- [ ] **fMRI 可视化**：使用 CanlabCore / 其他工具进行高质量结果呈现
- [ ] **多模态特征提取**：从视频中提取声学、面部表情、语言特征
- [ ] **实验 protocol**：理解 CAD Lab 实验全流程（HRV、内感受任务、临床访谈等）

### 长期目标（6-12个月）
- [ ] **计算精神病学**：理解计算建模在精神病理学中的应用（RL、贝叶斯大脑）
- [ ] **机器学习建模**：将影像/行为特征与临床症状（PHQ-9, GAD-7）关联分析
- [ ] **独立研究能力**：能独立完成从实验设计 → 数据采集 → 分析 → 论文的全流程
- [ ] **论文产出**：完成多模态自传体叙事 pilot 研究的分析与论文撰写

## 二、分阶段学习计划

### Phase 1：fMRI 基础与 SPM 入门（1-2个月）

| 周次 | 学习内容 | 资源 |
|------|---------|------|
| 第1周 | fMRI 原理：BOLD 信号、MRI 物理、T1 vs T2* | CADLAB Fmri workshop 资料 Step 1 + Martin Lindquist YouTube |
| 第2周 | 实验设计：Block / Event-Related / Mixed 设计 | 同上 + SPM 手册 Ch30-32 |
| 第3周 | MATLAB + SPM 环境搭建，BIDS 格式入门 | 资料 Step 2 + dcm2bids 教程 |
| 第4周 | **SPM 实验**：单被试 Block Design (Auditory data) | SPM 手册 Ch30 + Andy's Brain Book |
| 第5周 | **SPM 实验**：单被试 Event-Related (Face data) | SPM 手册 Ch31 + Andy's Brain Book |
| 第6周 | **SPM 实验**：组分析 (Face group RFX) | SPM 手册 Ch32 |
| 第7周 | pre-processing 理解：realign, coregister, segment, normalize, smooth | 资料 Step 1 补充 + 视频 |
| 第8周 | 复习与实操：完整跑一遍 SPM 分析流程 | Andy's Brain Book SPM 系列 |

### Phase 2：统计与机器学习基础（2-4个月）

| 周次 | 学习内容 | 资源 |
|------|---------|------|
| 第9-10周 | **线性代数**：向量、矩阵、特征值、SVD |  이상화 교수 / Gilbert Strang 18.06 |
| 第11-12周 | **统计学习导论**：回归、分类基础 | ISLR (statlearning.com) + 视频 |

| 第16周 | **GLM 与 fMRI**：一阶（被试内）+ 二阶（组分析）校正方法 | SPM 手册 + 统计资料补充 |

## 三、每周执行建议

**日常节奏：**
- **周一-周五**：每天 1-2 小时理论学习 + 实操
- **周六**：整理笔记 + 复习本周内容
- **周日**：休息 / 预习下周内容

**每日建议：**
1. 看 1 个视频 / 读 1 个章节
2. 动手实操（跑代码/分析）
3. 记录学习笔记（Notion / Obsidian）
4. 遇到的问题记录下来，每周集中解决
